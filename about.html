🌱 ABOUT CRAWBOT

Built for a better future.

CrawBot is a student-built robotics project focused on practical AI-powered waste sorting.

🎯 PROJECT GOAL

Make smart recycling more accessible.

The goal of CrawBot is to combine affordable electronics, robotics and artificial intelligence into a system that can identify and sort common waste materials.

🧩 MAIN SYSTEM
  • Arduino Mega 2560
  • Camera Detection
  • AI Classification
  • Bluetooth Control
  • Touchscreen Interface
  • Extendable Robotic Gripper
  • Voice Interaction
