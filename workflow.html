⚙️ SYSTEM WORKFLOW

From waste to sorting.

CrawBot is designed as a sequence of simple systems, with each part doing one job.

01
📷

Detect

The camera observes the item placed on the sorting platform.

02
🧠

Identify

The AI model determines what type of material the object is.

03
⚙️

Decide

CrawBot determines the correct sorting action and destination.

04
🦾

Pick

The extendable gripper reaches the object and securely holds it.

05
🔄

Move

The robotic arm moves the object toward its assigned sorting location.

06
♻️

Sort

The object is placed into the correct recycling category.

🦾 GRIPPER

Built for different sizes.

CrawBot is being designed to handle small items like wrappers and larger items like water bottles.

🛑 SAFETY

Stop before damage.

Emergency-stop controls and physical limit switches are planned for the robotic system.
